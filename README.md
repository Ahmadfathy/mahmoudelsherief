# Mahmoud Sherief Academy

واجهة React وVite عربية متصلة بباك Laravel الموجود في `../BackEnd`.

## التشغيل المحلي

شغّل الباك أولًا:

```bash
cd ../BackEnd
php artisan serve --host=127.0.0.1 --port=8000
```

ثم شغّل الفرونت:

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

عنوان الـAPI يُقرأ من `VITE_API_URL`، والقيمة المحلية الافتراضية:

```env
VITE_API_URL=http://127.0.0.1:8000/api/v1
```

## الشاشات المتصلة بالـAPI

- التسجيل والدخول برقم الموبايل والخروج باستخدام Laravel Sanctum.
- قائمة الكورسات وتفاصيل الكورس وصلاحية الاشتراك.
- طلب اشتراك جديد وتتبع تقدم الدروس.
- دفع Vodafone Cash أو InstaPay مع رفع الإيصال.
- لوحة الأدمن للكورسات والوحدات والدروس ورفع الفيديو.
- مراجعة طلبات الاشتراك والمدفوعات وتفعيل وصول الطالب.

لا تُخزن كلمات المرور أو بيانات الكورسات في `localStorage`. التخزين المحلي مستخدم فقط لحفظ Bearer Token الخاص بجلسة الطالب، بينما توكن الأدمن محفوظ في `sessionStorage`.

## Production build

```bash
npm run build
```

الملفات الناتجة توجد في `dist/`.

## الإعدادات العامة

بيانات التواصل والروابط في `lib/config.ts`، والنصوص التسويقية في `lib/content.ts`.
